Skyscraper · 楼高可见数推理

边上的数字写着：从那条边往里看，能看得见几栋楼

每行每列都是 1..n 的一个排列：1 是最矮的楼，n 是最高的那栋，谁也不会挡在它前面。 所以写着 1 的那条边一开口就说死了——第一格里站着的就是 n 楼；写着 n 的那条边则要求这一眼望进去一路升高。中间的数靠的是"这一行还剩哪几种摆法对得上两头的读数"， 几种摆法都同意的格子才能落子。 这里没有运气题：每一局都只有一个答案，而且每一局都不必回溯就能推到底——这两句话由 node tools/engine-test.mjs 与 npm run balance 在命令行里逐条断言， 难度分与档位区间都是量出来的，不是形容词。
